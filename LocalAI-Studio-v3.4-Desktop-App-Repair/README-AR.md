# LocalAI Studio — Chat Platform v3.4

هذه الحزمة مخصصة للمحادثة المحلية باستخدام Ollama وQwen. لا تتضمن مكوّنات إنشاء الصور أو الفيديو.

## تثبيت وتشغيل لأول مرة

1. تأكد أن Ollama يعمل بالفعل، وأن نموذج Qwen المحلي موجود كما هو موضح في إعدادك الحالي.
2. فك ضغط ملف ZIP كاملًا في أي مجلد عادي.
3. شغّل الملف **`SETUP-LOCALAI.bat`** مرة واحدة.
4. سيُفحص محتوى الحزمة، وتُنسخ ملفات التطبيق فقط إلى `D:\LocalAI\Platform`، ويُجهّز الإصلاح/التثبيت عند الحاجة، ثم ينشأ اختصار **LocalAI Studio** على سطح المكتب وقائمة Start وتُفتح نافذة التطبيق.

بعدها، التشغيل اليومي يكون من أيقونة **LocalAI Studio** على سطح المكتب. ستفتح الواجهة داخل نافذة تطبيق مستقلة باستخدام Edge أو Chrome بوضع التطبيق، وليست نافذة PowerShell أو ملف BAT.

واجهة الخدمة المحلية: http://127.0.0.1:8080

## تحديثات الإصدارات اللاحقة

عند استلام ZIP جديد:

1. فك ضغطه كاملًا في مجلد جديد.
2. شغّل **`SETUP-LOCALAI.bat`** من النسخة الجديدة.

هذا الملف نفسه يتحقق من الملفات والبصمات، ينسخ ملفات الإصدار المُدارة فقط، يحفظ النسخ السابقة، يحدّث اختصار سطح المكتب وأيقونته من ملف `Assets\LocalAI-Studio.ico`، ثم ينفذ الإصلاح والاختبارات ويفتح التطبيق. لا تحتاج إلى استبدال الاختصار أو تشغيل ملفات PowerShell يدويًا. فك الضغط وحده لا يشغّل ملفات تلقائيًا؛ لذلك شغّل ملف SETUP بعد كل تحديث.

## حماية Ollama وQwen والبيانات

- لا يثبت هذا المشروع Ollama من جديد، ولا يوقفه أو يحدّثه.
- لا يحذف أو ينقل مخزن النموذج `D:\LocalAI\Models`، ولا ينفذ `ollama pull` تلقائيًا.
- إعادة استخدام Qwen الموجود هي الوضع الطبيعي. عند وجود Manifest محلي، يفحص مدير النماذج بصمة SHA-256 لكل blob قبل اعتبار النموذج سليمًا. تنزيل Qwen تلقائيًا معطّل افتراضيًا.
- عند غياب النموذج أو تعذر التحقق من مخزن محلي، يعرض مدير النماذج السبب بدل تنزيل عدة جيجابايت دون إذن.
- ملفات نموذج موجودة لكنها تالفة أو ناقصة لا تُستبدل تلقائيًا؛ يتم توضيح المسارات التي فشل التحقق منها.
- أي استيراد لملفات Ollama يتحقق من SHA-256 ويستخدم ملفًا مؤقتًا قبل نقله إلى المخزن النشط.
- لا تحذف `D:\LocalAI\Models` أو `D:\LocalAI\Platform\Data` أو مجلدات `Backups` لمعالجة خطأ تشغيل؛ هذه المجلدات ليست ملفات تحديث.

## الصوت وWhisper (اختياري)

المحادثة النصية لا تحتاج إلى Whisper أو faster-whisper أو FFmpeg. لن يحاول الإعداد تثبيت مكتبات الصوت أو FFmpeg تلقائيًا، ولن يعتبر غيابها فشلًا في الدردشة النصية.

عند الحاجة إلى الصوت لاحقًا، ثبّت الاعتماديات الاختيارية داخل بيئة المشروع:

```powershell
D:\LocalAI\Platform\.venv\Scripts\python.exe -m pip install av==14.0.1 faster-whisper==1.2.1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File D:\LocalAI\Platform\ENSURE-MODELS.ps1 -RequireWhisper
```

قد يتطلب تجهيز نموذج Whisper تنزيل ملفاته لأول مرة. لا يُنفذ هذا الأمر ضمن التشغيل اليومي.

## النسخ الاحتياطية والاسترجاع

قبل تحديث ملفات الحزمة، يحفظ ملف SETUP النسخ السابقة في `D:\LocalAI\Backups\Setup-*`. ويحفظ مسار الإصلاح الملفات المُدارة في `D:\LocalAI\Backups\Platform-PreRepair-*` أو `Platform-PreUpdate-*`. إذا فشل نسخ الملفات أو إصلاح المنصة، يحاول النظام استرجاع النسخة السابقة. تبقى النسخ الاحتياطية محفوظة للمراجعة اليدوية.

لا يشمل تحديث الحزمة قاعدة محادثات Open WebUI أو مفاتيح التوقيع أو مجلد Ollama ونماذجه أو ملفات المستخدم غير الموجودة في Manifest.

## الفحوصات والإصلاحات

- يميز فاحص Manifest بين مجلد ZIP المستخرج ومجلد المنصة المثبتة؛ ملفات `.venv` والمحادثات والسجلات والأسرار والنسخ الاحتياطية لا تُحسب ملفات زائدة.
- تحفظ جميع ملفات PowerShell بترميز UTF-8 مع BOM لتوافق Windows PowerShell 5.1.
- يبقى Qwen والتفكير العميق والمراجعة الذاتية منفصلين: التفكير العميق والمراجعة الذاتية متوقفان افتراضيًا.
- يختبر الإصدار ملفات الفلاتر وسياسة التنزيل والنسخ الاحتياطي وسلامة ملفات النموذج وتمرير معاملات Windows.
- يتحقق مشغّل سطح المكتب من Ollama، ويبدأ Open WebUI فقط، ثم يفتح واجهة التطبيق. لا يوقف Ollama عند إغلاق نافذة المتصفح.
- يستمع Open WebUI إلى `127.0.0.1:8080` محليًا.

## أدوات الصيانة

تظل أدوات الصيانة متاحة من `D:\LocalAI\Platform\LocalAI-Studio.bat`:

| الأمر | الوظيفة |
|---|---|
| `LocalAI-Studio.bat repair` | إصلاح أو تثبيت منصة المحادثة |
| `LocalAI-Studio.bat stop` | إيقاف Open WebUI الذي يديره المشروع فقط؛ يترك Ollama يعمل |
| `LocalAI-Studio.bat check` | فحص المنصة وكتابة تقرير |
| `LocalAI-Studio.bat test` | إرسال طلب حقيقي إلى Qwen وقياس الأداء |
| `LocalAI-Studio.bat filters` | استيراد الفلاتر الاختيارية إلى Open WebUI |
| `LocalAI-Studio.bat restore-style` | استرجاع CSS الأصلي لـOpen WebUI |
| `LocalAI-Studio.bat verify` | فحص Manifest وPowerShell وملفات التشغيل |

## الفلاتر الاختيارية

1. **Trusted Content Guard** يعامل الملفات والاقتباسات ومخرجات الأدوات والصفحات الخارجية كبيانات غير موثوقة.
2. **Accuracy & Thinking** يضيف توجيهات الدقة. تشغيل التفكير العميق متوقف افتراضيًا ويمكن تفعيله من إعدادات الفلتر.
3. **Selective Self Review** يطلب استدعاءً ثانيًا من النموذج نفسه لمراجعة إجابات محددة. هو ليس تحققًا مستقلًا، ومتعطل افتراضيًا لتجنب زمن وكلفة استدلال إضافيين.

لاستيراد الفلاتر، أنشئ Admin API Key من Settings ثم شغّل `LocalAI-Studio.bat filters`. يُقرأ المفتاح بإدخال مخفي ولا يُحفظ في الحزمة. عند تحديث فلتر سبق استيراده، قد يحتفظ Open WebUI بقيم Valves التي اخترتها سابقًا؛ راجع الإعدادين `enable_qwen_thinking=false` و`enabled=false` لمراجعة الإجابات.

- سجلات المنصة: `D:\LocalAI\Logs` و`D:\LocalAI\Platform\Logs`.
- حالة المنصة: `D:\LocalAI\Platform\PLATFORM-STATUS.txt`.
- حالة النماذج: `D:\LocalAI\Platform\MODEL-STATUS.json` و`MODEL-STATUS.txt`.
