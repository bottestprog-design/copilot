# سجل التغييرات — LocalAI Studio v3.4 Desktop Chat

هذه نسخة تطوير وإصلاح محلية للحزمة السابقة. لم يتم تعديل أي فرع أو ملف أو Commit على GitHub. لا تتضمن هذه الحزمة مولدات صور أو فيديو.

## تجربة التطبيق والتحديث

- إضافة ملف واحد `SETUP-LOCALAI.bat` للتثبيت الأولي وتحديث الإصدارات اللاحقة.
- إنشاء اختصار Desktop وStart Menu باسم LocalAI Studio، يفتح الواجهة في نافذة Edge/Chrome بوضع التطبيق.
- تضمين أيقونة Windows متعددة الأحجام في `Assets/LocalAI-Studio.ico`، ويُعاد تحديث الأيقونة والاختصار مع كل تشغيل لملف SETUP.
- إضافة نافذة بدء صغيرة توضح حالة تشغيل الخدمة وتعرض رسالة خطأ واضحة بدل نافذة PowerShell صامتة.
- فصل التشغيل اليومي عن التثبيت والتحديث؛ التشغيل اليومي من أيقونة سطح المكتب، وSETUP لإصدار جديد.

## إصلاحات التوافق والتحقق

- إعادة كتابة `CHECK-LOCALAI.ps1` وتبسيط تشخيصاته لتجنب مشاكل parsing مع سلاسل النصوص والرموز غير ASCII.
- إعادة كتابة اختبار الاستدلال `VERIFY-MODEL.ps1` باستخدام Prompt إنجليزي ASCII وتوليد تقرير داخل مجلد السجلات بعد التأكد منه.
- إضافة UTF-8 BOM لجميع ملفات PowerShell لتوافق Windows PowerShell 5.1 مع النصوص متعددة البايت.
- جعل `VERIFY-PACKAGE.ps1` يميز بين مجلد ZIP المستخرج ومجلد التطبيق المثبت، حتى لا يصنف ملفات `.venv` والبيانات والسجلات والأسرار على أنها ملفات غير مدرجة.
- إضافة اختبار إصدار `TEST-RELEASE.py` يراجع Manifest والبصمات وملفات الإعداد والأيقونة والسياسات الأساسية.

## جعل الصوت اختياريًا فعلًا

- إصلاح شرط `REPAIR-AND-RESUME.ps1`: وجود Open WebUI الأساسي يكفي لتحديث ملفات المشروع؛ غياب مكتبات الصوت لا يفرض إعادة تثبيت المنصة.
- إيقاف فرض تثبيت PyAV وfaster-whisper وFFmpeg ضمن إعداد الدردشة النصية.
- الاكتفاء بفحص وجود مكونات الصوت، مع إظهار حالتها كميزة اختيارية.
- تبقى خطوة Whisper متاحة عند الطلب عبر التثبيت اليدوي للاعتماديات ثم `ENSURE-MODELS.ps1 -RequireWhisper`.

## استمرار الحماية

- إضافة فحص SHA-256 لملفات النموذج حتى عند وجود Qwen بالفعل في Ollama API؛ وإذا لم يعثر على Manifest محلي يوضح ذلك بدل الادعاء بأن البلوكات تم التحقق منها.
- Qwen auto-download معطل افتراضيًا.
- لا يتم إيقاف Ollama أو إعادة تثبيته أو حذف/نقل نموذج Qwen أو قاعدة المحادثات.
- التحديثات تنسخ الملفات المدرجة في Manifest فقط، وتحتفظ بالنسخ السابقة خارج مجلد بيانات المستخدم.
- يظل Qwen والتفكير العميق ومراجعة الإجابات إعدادات منفصلة؛ التفكير العميق والمراجعة الذاتية متوقفان افتراضيًا.
