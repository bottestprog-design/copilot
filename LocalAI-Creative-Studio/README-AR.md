# LocalAI Creative Studio — دليل التشغيل والتطوير

**الإصدار: 1.11.2 — Desktop Edition**

استوديو محلي عربي لإنشاء الصور والفيديو عبر **ComfyUI**، مع استخدام **Ollama/Qwen** اختيارياً لتحسين وصف التوليد. يعمل كنافذة تطبيق مستقلة على Windows، ويُدار من اختصار سطح المكتب بعد التثبيت الأول.

> **حدود المسؤولية:** هذا المشروع هو واجهة وتنسيق مهام محلي، وليس محرك توليد بحد ذاته. يحتاج توليد الصور والفيديو إلى ComfyUI ونماذج وأوزان متوافقة. Ollama اختياري لتحسين الأوصاف. لا يثبت الاستوديو ولا يوقف ولا يحذف ولا ينقل Ollama أو Qwen أو Open WebUI أو ComfyUI أو بياناتها.

## ابدأ من هنا

### التثبيت الأول

1. فك ضغط ZIP بالكامل إلى مجلد عادي. لا تشغّل الملفات من معاينة الأرشيف.
2. انقر نقراً مزدوجاً على `SETUP-AND-START.bat`.
3. يتحقق المثبّت من الحزمة ثم يبحث عن CPython مناسب. إذا لم يجد Python 64-bit صالحاً (3.11–3.14)، ينزّل CPython 3.14.10 x64 الرسمي من `python.org`، ويتحقق من SHA-256 وتوقيع Authenticode وهوية Python Software Foundation قبل تشغيله.
4. يجهّز Python خاصاً بالاستوديو، وينشئ `.venv`، ويثبت الاعتماديات، ويشغّل فحوص الاستيراد ومجموعة الاختبارات كاملة قبل اعتماد البيئة أو إنشاء الاختصار.
5. بعد نجاح الفحوص فقط، ينشئ اختصار سطح المكتب وقائمة Start ويحدّث أيقونة LocalAI، ثم يفتح نافذة التطبيق.

**إذا كان مجلد التثبيت الافتراضي موجوداً ولا يمكن إثبات ملكيته:** لا يحذف المثبّت هذا المجلد ولا ينقله ولا يكتب فوقه. يبحث أولاً عن نسخة LocalAI سابقة يمكن التحقق منها؛ وإذا لم يجدها، يختار مجلداً جديداً مثل `%LOCALAPPDATA%\Programs\LocalAI Creative Studio (Managed)` أو اسماً مرقماً متاحاً. تحفظ النسخة الجديدة علامة ملكية بمسارها، وتستخدم أدوات التحديث والتشغيل والتشخيص واختبار المشروع المسار الموثوق نفسه لاحقاً. اترك المجلد القديم كما هو إلى أن تفحص محتوياته بنفسك.

### الاستخدام اليومي

انقر مرتين على أيقونة **LocalAI Creative Studio** على سطح المكتب. لا تحتاج إلى فتح PowerShell أو CMD أو مجلد المشروع. يفتح التطبيق في نافذة Edge/Chrome مستقلة عندما يكون أحدهما مثبتاً؛ وإذا لم يجدهما يستخدم المتصفح الافتراضي كخطة احتياطية.

### تحديث إصدار جديد

1. فك ضغط ZIP الجديد إلى مجلد عادي.
2. شغّل `APPLY-UPDATE.bat` من الحزمة الجديدة.
3. يتحقق المحدّث من الحزمة، يجهّز نسخة مرحلية، يوقف خدمة الاستوديو فقط، ثم ينسخ الملفات ويعيد التحقق منها.
4. يختبر Python والاعتماديات والتطبيق ومجموعة الاختبارات، ثم يحدث اختصار LocalAI والأيقونة وفق بصمة الملف الجديد.
5. بعد نجاح التحديث استمر باستخدام أيقونة سطح المكتب. لا تنسخ ملفات ZIP يدوياً إلى مجلد التثبيت.

يمكن أيضاً تشغيل `SETUP-AND-START.bat` من حزمة جديدة؛ يكتشف التثبيت السابق ويحوّل العملية إلى تحديث آمن.

## حماية البرامج والأيقونات الأخرى

هذه قاعدة أساسية في التثبيت والتحديث:

- لا يجري المشروع مسحاً شاملاً لسطح المكتب أو قائمة Start، ولا يستخدم `robocopy /MIR`.
- لا يحذف أو يستبدل اختصاراً موجوداً لا يستطيع إثبات أنه يعود إلى LocalAI Creative Studio.
- عند وجود اختصار آخر باسم `LocalAI Creative Studio.lnk` ينشئ اسماً بديلاً مثل `LocalAI Creative Studio (2).lnk` بدلاً من لمس الاختصار الموجود.
- لا يحذف مجلدات البرامج أو اختصارات البرامج الأخرى، ولا يغيّر PATH العام أو تسجيل امتدادات الملفات أو Python Launcher العام.
- لا يحذف ملفات التطبيق القديمة إلا إذا كانت مدرجة في Manifest الإصدار السابق وما زالت بصمتها الحالية مطابقة للبصمة المسجلة. الملفات المعدلة محلياً تُترك.
- يستخدم التحديث نسخاً مرحلياً ونسخة احتياطية، ويتحقق من كل ملف قبل اعتماده. عند فشل التحقق يحاول استعادة ملفات الإصدار السابق.
- لا يثبت أو يحدّث أوزان النماذج ولا يغير مجلد نماذج Ollama أو ComfyUI.

**تنبيه تقني:** Windows لا يشغّل ملفاً تلقائياً لمجرد فك ضغط ZIP، وهذا مقصود. لذلك يتطلب كل إصدار جديد نقرة واحدة على `APPLY-UPDATE.bat` لتطبيق التحديث. بعد ذلك تكون الأيقونة هي طريقة التشغيل اليومية.

## ما الذي يقدمه الاستوديو؟

- واجهة عربية RTL محلية على `http://127.0.0.1:7865`.
- إنشاء صور وفيديو عبر ComfyUI API Workflows.
- تحسين اختياري لوصف التوليد عبر Ollama/Qwen المحلي.
- رفع صورة مرجعية لمسارات Image-to-Image وImage-to-Video التي تدعم ذلك.
- التحكم في seed والدقة والخطوات وCFG وعدد الإطارات وFPS والدفعة عندما يوفر الـ Workflow مدخلات مقابلة.
- طابور التوليد وحالة المهام وسجل SQLite محلي ومعرض للنتائج.
- استيراد ComfyUI API Workflows وربط المدخلات وتعديل إعداداتها.
- تشخيص حالة الخدمات والعتاد والمساحة ومجلدات النماذج.
- تحديد الخدمات على loopback ورفض عناوين LAN أو الإنترنت، مع حماية طلبات التعديل من Cross-Origin.
- يحصر مسح الطابور في المهام المسجلة من الاستوديو؛ ولا يمسح مهام المستخدمين الآخرين في ComfyUI.

## المحركات المحلية

| المحرك | العنوان الافتراضي | الاستخدام |
|---|---|---|
| ComfyUI | `http://127.0.0.1:8188` | ضروري لتوليد الصور والفيديو |
| Ollama | `http://127.0.0.1:11434` | اختياري لتحسين الوصف بنموذج Qwen |
| LocalAI Creative Studio | `http://127.0.0.1:7865` | واجهة الاستوديو المحلية |

لا يعتمد الاستوديو على Open WebUI. وجود Open WebUI أو غيابه لا يمنع الاستوديو من العمل، ولا يغير المشروع إعداداته.

## Workflows المرفقة

توجد قوالب API جاهزة في `data/workflows/` وملفات إعداد وربط مقابلة في `data/configs/`.

| Workflow | المهمة | الملاحظات والترخيص |
|---|---|---|
| FLUX.2 Klein 4B | نص إلى صورة | يتطلب diffusion model وtext encoder وVAE المناسبة. نسخة 4B وفق مصدر النموذج بترخيص Apache 2.0. |
| Qwen-Image-2512 | نص إلى صورة | نموذج ثقيل؛ راجع أوزان ComfyUI وترخيص النموذج قبل الاستخدام التجاري. |
| Qwen-Image 2.1 | نص إلى صورة | قالب ComfyUI يستخدم ملفات INT8. ترخيص Qwen Research License غير تجاري؛ لا تستخدمه تجارياً دون إذن مستقل. |
| Wan 2.2 TI2V 5B | نص إلى فيديو | قالب API من أمثلة ComfyUI الرسمية؛ يتطلب أوزان Wan 2.2 ومكونات النص وVAE. |
| Wan 2.2 TI2V 5B | صورة إلى فيديو | يستخدم صورة بداية، ويتطلب توافر عقد تحميل الصور ومكونات Wan. |
| SDXL Standard | نص إلى صورة | قالب عام؛ يحتاج checkpoint متوافقاً يختاره المستخدم. |

القوالب لا تحتوي على أوزان النماذج. لا تُنزّل جميع النماذج دفعة واحدة؛ ابدأ بنموذج يناسب VRAM والذاكرة والمساحة المتاحة. بعض القوالب تتطلب إصدار ComfyUI حديثاً أو عقداً غير موجودة في الإصدارات الأقدم. عند ظهور خطأ عقدة مفقودة، حدّث ComfyUI أو استخدم Workflow مطابقاً لإصدارك.

## Python والاعتماديات

- يبحث المثبّت عن CPython 3.11–3.14، 64-bit، ويختبر وجود `pip` و`venv` و`SSL` و`SQLite`.
- إذا لم يجد نسخة صالحة، يستخدم CPython 3.14.10 الرسمي المثبت للمستخدم داخل مجلد runtime خاص بـ LocalAI. لا يغيّر PATH ولا يثبت Launcher على مستوى النظام ولا يطلب صلاحيات مدير النظام.
- تُثبت مكتبات التطبيق في `.venv` منفصلة.
- الاعتماديات في `requirements.txt` محددة بنطاقات مستقرة مع حد أدنى وحد أعلى للـ major version. هذا يسمح بتحديثات متوافقة بدلاً من ربط التطبيق بنسخة واحدة قديمة.
- قبل ترقية `.venv`، ينشئ المثبّت بيئة مرشحة، يثبت الحزم باستخدام Wheels الثنائية فقط، يشغّل `pip check`، يترجم ملفات Python، يستورد التطبيق، ثم يشغّل مجموعة الاختبارات كاملة. لا يبدّل البيئة الحالية إلا بعد نجاح ذلك.
- إذا فشل الاختبار، لا يُعتمد `.venv` المرشحة ولا يتم تحديث اختصار سطح المكتب؛ تبقى البيئة السابقة محفوظة.

## البيانات والسجلات

تُحفظ البيانات خارج مجلد البرنامج حتى لا تُمسح عند التحديث:

- المسار الافتراضي: `%LOCALAPPDATA%\LocalAI\CreativeStudioData`.
- إذا كان `D:\LocalAI` موجوداً عند أول تشغيل، يمكن استخدام `D:\LocalAI\CreativeStudioData` للحفاظ على بيانات التثبيت القديمة في مسار D. يسجل المشروع المسار المختار ويعيد استخدامه في التشغيل والتحديث.
- السجلات: مجلد `logs` داخل مجلد البيانات.
- إعدادات الاستوديو وقاعدة SQLite والمهام والـ Workflows المستوردة والملفات الناتجة محفوظة في مجلد البيانات، وليست ضمن ملفات التحديث.
- ملفات Python runtime الخاصة بالاستوديو: `%LOCALAPPDATA%\LocalAI\CreativeStudioRuntime`.

لا تنقل مجلد بيانات الاستوديو أو تعِد تسمية ملفات SQLite أثناء تشغيل الخدمة. انسخ المجلد كاملاً بعد إيقاف الاستوديو إذا أردت نسخة احتياطية.

## الفحص واستكشاف الأخطاء

| الملف | الوظيفة |
|---|---|
| `VERIFY-PACKAGE.bat` | التحقق من SHA-256 وكشف الملفات غير المدرجة أو المسارات غير الآمنة |
| `CHECK-STUDIO.bat` | تشخيص الخدمات والاتصالات والنموذج المحلي دون تثبيت أو حذف أو إعادة تشغيل أي محرك |
| `RUN-TESTS.bat` | تشغيل مجموعة الاختبارات بعد إعداد البيئة |
| `STOP-STUDIO.bat` | إيقاف خدمة الاستوديو فقط |
| `REBUILD-MANIFEST.bat` | للمطورين: إعادة بناء Manifest بعد مراجعة كل تغيير |

إذا فشل التثبيت، افتح أحدث ملف `desktop-setup-*.log` داخل مجلد `logs`. إذا فشل التحديث، افتح أحدث ملف `desktop-update-*.log`. لا تحذف `.venv` أو قاعدة البيانات أو مجلدات النماذج لمحاولة الإصلاح دون قراءة التقرير أولاً.

## ملاحظات للمطورين — كيف تجعل الإصدار قابلاً للتطوير؟

1. غيّر رقم الإصدار في `VERSION.txt` فقط؛ يقرأ خادم API والواجهة القيمة منه وقت التشغيل.
2. عند تعديل API أو التخزين أو الواجهة، أضف اختباراً يثبت السلوك الجديد واختباراً للحالة الفاشلة أو الحدود ذات الصلة.
3. عند تغيير اعتماديات Python، عدّل النطاقات في `requirements.txt`. لا تعتمد الحزمة قبل نجاح مجموعة الاختبارات الكاملة في البيئة المرشحة.
4. عند إضافة Workflow، أضف ملف JSON في `data/workflows/` وملف config بالاسم نفسه في `data/configs/`. وضّح مصدر الـ Workflow ومتطلبات الأوزان والترخيص، واختبر كل رابط عقدة ومدخل.
5. حافظ على أسماء ملفات BAT/VBS وملف ownership marker ومسارات البيانات؛ هذه عقود توافق مع الاختصارات والتثبيت الموجود.
6. لا تغيّر سياسة حماية Desktop/Start Menu. لا تستخدم أوامر مزامنة تدميرية، ولا تزل ملفات قديمة إلا وفق Manifest السابق وبصمتها.
7. شغّل `RUN-TESTS.bat`، ثم `REBUILD-MANIFEST.bat`، ثم `VERIFY-PACKAGE.bat`. بعد ذلك أنشئ ZIP كاملاً مع مجلد المشروع وبصمة SHA-256 للـ ZIP.
8. اختبر ملفات `.ps1` و`.bat` فعلياً على Windows 10/11 قبل إعلان الإصدار نهائياً، ثم اختبر تثبيتاً نظيفاً وتحديثاً فوق إصدار سابق. اختبارات Linux لا تعوّض تجربة COM Shortcuts وAuthenticode وWindows Installer.

## حدود التحقق

يمكن اختبار كود Python وواجهة JavaScript وملفات JSON وخادم HTTP داخل بيئة البناء. لا يمكن اعتبار توليد صورة أو فيديو مثبتاً إلا بعد توفر ComfyUI والأوزان والعقد المطلوبة وتشغيل مهمة فعلية على GPU. كما يلزم اختبار مثبت PowerShell وملفات BAT وVBS على Windows حقيقي؛ لا أدعي نجاح تشغيل Windows Installer في بيئة Linux.
