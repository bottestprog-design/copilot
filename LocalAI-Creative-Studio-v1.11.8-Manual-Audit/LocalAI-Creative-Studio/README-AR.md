# LocalAI Creative Studio 1.11.8 — دليل التشغيل العربي

إصدار مكتبي محلي لواجهة إنشاء الصور والفيديو عبر **ComfyUI**، مع تكامل اختياري مع **Ollama/Qwen** لتحسين الأوصاف. المشروع لا يتضمن أوزان النماذج ولا يشغّل التوليد بنفسه؛ يحتاج ComfyUI وعُقده والأوزان المناسبة.

## حماية بيئتك وبياناتك

- لا يثبّت هذا الاستوديو Ollama أو ComfyUI أو Open WebUI.
- لا يوقف Ollama، ولا يسحب أو يحذف أو ينقل نماذج Qwen.
- لا يغيّر مجلدات النماذج أو بيانات ComfyUI.
- لا يمسح سطح المكتب أو قائمة Start، ولا يستبدل اختصارات لا يستطيع إثبات ملكيتها للاستوديو.
- ملفات بيانات الاستوديو وقاعدة البيانات والـ Workflows المستوردة والوسائط والسجلات محفوظة خارج مجلد البرنامج.
- التحديث لا يستخدم `robocopy /MIR`، ويحافظ على الملفات المحلية التي تغيّرت ولا تحذفها بصمة الإصدار السابق.
- خدمة Studio مربوطة على `127.0.0.1:7865` فقط. لا تحولها إلى عنوان LAN أو Internet. الواجهة لا تستدعي Google Fonts أو CDN؛ تستخدم خطوط النظام وملفات الأصول المرفقة.

## مسارات البيانات

يُختار مسار البيانات عند أول تثبيت ويُسجل في `CreativeStudioDataRoot.txt`:

1. `%LOCALAPPDATA%\LocalAI\CreativeStudioData`
2. `D:\LocalAI\CreativeStudioData` إذا كان مجلد `D:\LocalAI` موجوداً عند أول تشغيل.

يجب ترك المسار المسجل كما هو حتى عند التحديث. لا تنقل قاعدة SQLite أو مجلد `workflows` أثناء تشغيل الاستوديو. لإجراء نسخة احتياطية، أوقف الاستوديو ثم انسخ مجلد `CreativeStudioData` كاملاً.

Runtime Python الخاص بالاستوديو يوجد في `%LOCALAPPDATA%\LocalAI\CreativeStudioRuntime`، أما `.venv` فتوجد داخل مجلد التطبيق.

## التثبيت الأول على Windows 10/11

1. فك ضغط ZIP كاملاً إلى مجلد عادي، ولا تشغّل الملفات من معاينة الأرشيف.
2. شغّل `SETUP-AND-START.bat`.
3. يتحقق المثبّت من ملفات الحزمة عبر `MANIFEST-SHA256.txt`.
4. يبحث عن CPython 64-bit مدعوم. عند الحاجة ينزّل مثبت CPython الرسمي المثبت برقم إصدار وبصمة SHA-256، ويفحص توقيع Authenticode قبل تشغيله.
5. ينشئ بيئة Python خاصة بالاستوديو ويثبت الاعتماديات في `.venv`.
6. يفحص الاعتماديات واستيراد التطبيق ومجموعة الاختبارات قبل اعتماد البيئة وإنشاء الاختصار.
7. بعد النجاح، شغّل الاستوديو لاحقاً من اختصار سطح المكتب.

إذا كان مجلد التثبيت الافتراضي مشغولاً ولا يمكن إثبات ملكيته، يتركه المثبّت دون لمس ويختار مجلداً جانبياً جديداً. لا تحذف المجلد القديم لمجرد أنه يحمل اسماً مشابهاً.

## الاستخدام

- **ComfyUI:** `http://127.0.0.1:8188` — ضروري لتوليد الصور والفيديو.
- **Ollama:** `http://127.0.0.1:11434` — اختياري لتحسين الأوصاف.
- **Studio:** `http://127.0.0.1:7865` — واجهة الاستوديو المحلية.

من واجهة الاستوديو اختر نوع المهمة، ثم Workflow مناسباً. احفظ `API Workflow` من ComfyUI بعد تفعيل Developer Mode، واستورده من صفحة سير العمل. راجع المدخلات المرتبطة (Positive Prompt، Seed، المقاس، الإطارات والصورة المرجعية) قبل أول توليد.

تحتاج مسارات Image-to-Video إلى صورة مرجعية ومدخل `LoadImage` مرتبط. أما Text-to-Video فلا يتطلب رفع صورة. ليست كل Workflows قابلة للتشغيل على كل إصدار ComfyUI؛ قد تحتاج بعض العقد إلى إصدار أحدث أو Custom Nodes موثوقة.

## Workflows المرفقة

ملفات `data/workflows/` هي رسوم API، وملفات `data/configs/` تحمل المهمة والترخيص والمصدر والـ bindings. يجب أن يتطابق اسم الملف في المجلدين.

| المسار | الوظيفة | ملاحظات |
|---|---|---|
| FLUX.2 Klein 4B | نص إلى صورة | يتطلب diffusion model وtext encoder وVAE متوافقة |
| Qwen-Image 2.1 | نص إلى صورة | ترخيص Qwen Research غير تجاري؛ راجع الترخيص قبل الاستخدام |
| Qwen-Image-2512 | نص إلى صورة | نموذج ثقيل ويحتاج ذاكرة/offload مناسبين |
| SDXL Standard | نص إلى صورة | يتطلب Checkpoint متوافقاً مثبتاً في ComfyUI |
| Wan 2.2 TI2V 5B | نص إلى فيديو | يستخدم مسار T2V دون صورة مرجعية |
| Wan 2.2 TI2V 5B | صورة إلى فيديو | يتطلب صورة بداية |

لا تحتوي الحزمة على الأوزان. لا تنزّل النماذج عشوائياً أو دفعة واحدة؛ قارن ذاكرة GPU والمساحة الحرة ومتطلبات ComfyUI وترخيص النموذج أولاً.

## التحديث الآمن

1. فك ضغط ZIP الجديد إلى مجلد عادي.
2. شغّل `APPLY-UPDATE.bat` من الحزمة الجديدة.
3. يتحقق المحدّث من الحزمة ويجهّز Stage منفصلاً ويفحص بصماته.
4. يأخذ نسخة احتياطية من الملفات التي ستتغير ويتحقق من SHA-256 للنسخ الاحتياطية.
5. يوقف خدمة Studio فقط بعد اكتمال النسخ الاحتياطية، وينتظر تحرير المنفذ 7865.
6. ينسخ الملفات ويفحصها، ثم يهيئ Python والاعتماديات ويجري فحص التطبيق.
7. عند فشل التحديث يحاول استعادة الملفات التي تطابق نسخها الاحتياطية، ثم يعيد تشغيل خدمة Studio إذا كانت تعمل قبل التحديث.

لا تنسخ ملفات ZIP يدوياً إلى مجلد التثبيت. لا تحذف `.venv` أو `CreativeStudioData` أو ملفات النماذج لمحاولة إصلاح مشكلة قبل قراءة التقرير.

## التشخيص والسجلات

- `VERIFY-PACKAGE.bat`: فحص بنية الحزمة والبصمات والمسارات.
- الأيقونات المرفقة هي أصول محلية بقياسات PWA 192/512 وWindows ICO متعدد المقاسات؛ لا تحتاج إلى تنزيل أيقونات عند التشغيل.
- `CHECK-STUDIO.bat`: فحص حالة Studio وComfyUI وOllama والنموذج الحالي دون تنزيل أو حذف أو إعادة تشغيل المحركات.
- `RUN-TESTS.bat`: تشغيل اختبارات الوحدة بعد تجهيز البيئة.
- `STOP-STUDIO.bat`: إيقاف خدمة Studio فقط.
- `REBUILD-MANIFEST.bat`: للمطورين فقط بعد مراجعة التغييرات.

السجلات في `CreativeStudioData\logs`. احتفظ بالسجل كاملاً عند حدوث فشل، ولا تشارك ملفات قاعدة البيانات أو الإعدادات إذا كانت تحتوي معلومات خاصة.

## حدود التحقق

المراجعة الحالية تشمل قراءة المصدر وربط الواجهة بخادم API، ومسارات البيانات، وملفات JSON والـ Workflows، والأصول، وبناء Manifest ومطابقة بصمات كل ملف مضمّن. لا يمكن من بيئة Linux إثبات سلوك Windows PowerShell 5.1 وCOM shortcuts وBAT/VBS والتحديث/rollback على Windows فعلي. كما لا يمكن إثبات توليد صورة/فيديو حقيقي دون ComfyUI والأوزان وGPU متوافقين. لا تعتبر هذه الحدود ناجحة لمجرد نجاح اختبار Python.
